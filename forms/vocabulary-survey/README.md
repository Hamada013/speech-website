# تقييم المفردات / Vocabulary survey

Arabic receptive and expressive checklists, child profiles, and reports saved in IndexedDB on the current device. No backend or child-data upload. Existing sessions migrate into reusable profiles; switching between tests fills the same child's details. Edits affect future tests; historical metadata remains a snapshot. Child codes are generated randomly by default and kept read-only; users enter the child’s name. Existing codes remain unchanged. Codes are stable, case-insensitive identifiers. Device/browser storage deletion removes records; JSON/CSV exports provide portable copies, and importing a session restores its child profile.

Serve the repository root: `python3 -m http.server 8000`, then open `/forms/vocabulary-survey/`. Deploy the repository with its existing `tools/VSS/voc` images and audio at the same relative paths. Other apps and their caches are independent.

## Word lists

Each of the four existing age groups has exactly **50 distinct receptive words** and **100 distinct expressive words**. Expressive setup offers **50 or 100**; the shorter test uses the same first 50 words every time. Presentation order is shuffled, membership and distractor identities are fixed. The bank numbers each item and marks the expressive core 50. `assets/word-lists.js` records explicit IDs, generated by `scripts/build-checklists.mjs` from editable everyday-word priorities. Existing clinician cohort overrides are respected and may change group counts.

These are curated local Arabic checklists using the supplied Syrian/Levantine media, **not a verified “50 most frequent” corpus ranking**, standardized age norms, or a validated adaptation of another instrument. There is no language selection backed by translated media. Broader child vocabulary varies by dialect, context and naming conditions. The [Open Arabic CDI](https://www.psy.plymouth.ac.uk/OpenArabicCDI/) concerns ages 8–30 months and does not validate this app's four age bands. [ASHA communication milestones](https://www.asha.org/public/developmental-milestones/communication-milestones/) are general guidance, not a diagnostic instrument. No age-equivalent score is fabricated.

Receptive targets retain the original strict four-picture matrix: target, spelling-similar candidate, cross-folder semantic candidate, and unrelated control; distinct labels and image content are required. This limits which everyday words can be included. Sound similarity is an unreviewed spelling proxy. Review images, word/audio agreement, dialect, cohort assignments and distractors before clinical use. Twelve later descriptive concepts expand the receptive 4–5 group; expressive community/profession words extend the 6+ group. These assignments are local proposals. Existing saved tests preserve their original item/media revisions.

Expressive modeled naming plays the word before grading. Unprompted naming withholds the model, while manual playback is recorded. Mastered = 1, learning = 0.5 in the separately labeled weighted index. Mastery percentage counts only fully correct words. Skips are excluded and shown separately.

## Reports

Four keyboard-accessible tabs: results, progress, age comparison, and item responses. Results show assessed/planned counts, group bars, mastered/learning/follow-up words and receptive choice errors. Print/PDF includes all tabs, including item details.

Repeat-test line graphs automatically use one common set of scored words across all included prior completed assessments of the same child, language and test mode. Item revision, cohort, choice sets and actual audio prompting must match at every point. Increases and declines are absolute percentage-point changes. Changing from 50 to 100 words does not manufacture improvement from the added items. Partial current reports are labeled and can compare only their shared scored items. If no common set exists, the chart shows an empty state. The selected-baseline bars are a separate pairwise comparison.

Age comparison uses other children's **local saved/imported completed results**, with age at assessment within ±3 months, matching language, test mode, exact word set, cohort, media revision, choice sets and per-word audio prompting, without skips. Each other child contributes one latest eligible record no later than the current assessment date. It shows count, median and range without peer names. This is a convenience sample, **not population norms or a diagnostic percentile**. Missing DOB, incomplete tests or absent compatible peers produce an honest empty state.

## PWA / PWABuilder

Run `npm run build --prefix forms/vocabulary-survey` after editing. The builder regenerates vocabulary data, fixed lists and an integrity-hashed offline release. Deploy over HTTPS, then supply the **deployed app URL** (ending `/forms/vocabulary-survey/`) to PWABuilder. `manifest.json` has a stable ID, standalone scope/start URL, 192/512 icons, a maskable icon, shortcut and mobile/desktop screenshots. Package/store signing happens in PWABuilder with the site owner's credentials; this repository does not contain signing keys or a packaged store binary.

Installing saves the local shell. The download icon offers installation plus an opt-in resumable download of all 1,990 existing WebP/M4A media files. The worker is scoped to this app, uses integrity checks, batches files sequentially, supports audio ranges and preserves other apps' caches. Browser storage may be evicted; exports are the portable backup. Updates activate after older app windows close.

## Checks

- `npm test --prefix forms/vocabulary-survey`: strict matrices, bank counts, nested 50/100 membership, scoring, imports, exports, matched-word progress/decline, peer exclusions and PWA integrity.
- `SURVEY_PLAYWRIGHT="$PWD/tools/VSS/voc/node_modules/playwright" SURVEY_SMOKE=1 node forms/vocabulary-survey/tests/browser.cjs`: Chromium + WebKit smoke checks; omit `SURVEY_SMOKE` for complete media-download/offline validation.
- `SURVEY_PLAYWRIGHT="$PWD/tools/VSS/voc/node_modules/playwright" node forms/vocabulary-survey/tests/profiles-browser.cjs`: profile edits/linking/reload/isolation, report tabs, repeat/peer graphs, responsive layout, screenshots and offline profile reopening.

The browser regressions use synthetic records only. `SURVEY_ENGINE=chromium` or `webkit` selects one engine. The original five-trial smoke fixtures inject a test-only sample option; production setup exposes only 50 (receptive) or 50/100 (expressive).

## App artwork

`assets/logo-source.jpg` is the supplied Language Test artwork. The header, home, browser favicons, Apple touch icon, manifest and shortcut use local exports in `icons/`. Maskable exports fit the complete artwork within the central safe circle. Regenerate with `SURVEY_PLAYWRIGHT="$PWD/tools/VSS/voc/node_modules/playwright" npm run build:icons --prefix forms/vocabulary-survey`, refresh install screenshots with `SURVEY_SCREENSHOTS=1 SURVEY_ENGINE=chromium` on the profile browser check, then rebuild the PWA release.
