# Original simple cartoon scenes

Created with the built-in ImageGen tool on 2026-10-31. These four illustrations replace the initial realistic-style drafts. The realistic drafts are not referenced by the app.

The selected source PNGs are saved beside this file; runtime WebP versions are in `../images/scene-*.webp`. Compression preserves the full scene without semantic editing. The other 629 runtime cards are locally copied from the existing VOC cartoon library, with their original Arabic labels retained. They were not newly generated for this change.

## Shared prompt

Use case: scientific-educational. Create a SIMPLE FLAT 2D CARTOON illustration for preschool picture-based language tasks. Plain white background, bold smooth dark outlines, flat solid cheerful colors, very minimal detail, friendly simple round faces with dot eyes, basic geometric forms, clean sticker-like cartoon people. NO realism, NO photographic detail, NO 3D, NO painterly texture, NO gradients, NO lighting effects, NO detailed backgrounds. A few clearly separated actions arranged in one simple scene, not panels. Landscape 3:2. Complete objects in frame with lots of white space. NO written words, letters, numbers, labels, arrows, checks, logos or watermarks. Characters modestly fully clothed, dark hair. Original artwork.

## Task coverage

Generalization sets use genuinely different existing illustrations where available; no mirrored copies or recolored versions are counted as independent exemplars. High-volume repertoire milestones and real-object/interaction tasks need additional assessor-provided evidence and materials beyond these supporting pictures.
