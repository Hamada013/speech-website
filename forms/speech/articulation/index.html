About This App

Informal articulation test for Arabic sounds created by SLP Ahmad Ghanem.

Assesses speech using S (Substitution), O (Omission), D (Distortion), A (Addition) across word positions (F, M, L). Predictions of phonological processes are limited and should be interpreted clinically.

Words/images chosen for children; therapists should adapt creatively.

Reports can be downloaded for documentation.

Clinical Summary of Phonological Processes

Stopping

Description: Fricative/affricate → stop consonant. Example: sun→tun. Note: Normal till ~3.5–5 yrs.

Denasalization

Description: Nasal → oral stop. Example: more→bore. Note: Place maintained.

Liquid Stopping

Description: Liquid → stop. Example: run→dun.

Vowel Consonantization

Description: ATYPICAL. Vowel→consonant. Example: up→bup. Red flag.

Glottal Replacement

Description: Sound→glottal stop. Example: cat→caʔ.

Fronting

Description: Velar→alveolar. Example: car→tar.

Backing

Description: ATYPICAL. Front→velar. Example: tea→key.

Gliding

Description: Liquid→glide. Example: rabbit→wabbit.

Liquid Substitution

Description: /l/↔/r/ swap. Example: rock→lock.

Liquidization

Description: Glide→liquid. Rare.

Vowel Substitution

Description: Vowel replaced by another. Example: sheep→ship.

Monophthongization

Description: Diphthong→pure vowel. Example: time→tom.

Diphthongization

Description: Pure vowel→diphthong. Example: bed→bayed.

Diphthong Substitution

Description: One diphthong→another. Example: house→hice.

Deaffrication

Description: Affricate→fricative/stop. Example: chip→ship.

Affrication

Description: Fricative/stop→affricate. Example: ship→chip.
